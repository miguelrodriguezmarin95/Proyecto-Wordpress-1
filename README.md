# Proyecto Wordpress 1 — Managger Murcia

## Descripción

Este repositorio contiene una muestra estática del sitio web [managgermurcia.com](https://managgermurcia.com/), desarrollado originalmente en WordPress con WooCommerce y Elementor, dentro del programa Kit Digital.

El contenido aquí publicado es una captura estática (HTML, CSS, JavaScript e imágenes) del sitio original, generada con fines de portfolio y demostración de diseño y maquetación. No incluye funcionalidades dinámicas del backend original (carrito de compra, gestión de pedidos, panel de administración, formularios funcionales, etc.), ya que estas dependían del CMS y del servidor de la web de origen.

## Origen del proyecto

- **Sitio original:** [https://managgermurcia.com/](https://managgermurcia.com/)
- **Tecnología original:** WordPress + WooCommerce + Elementor
- **Financiación:** Proyecto desarrollado en el marco del programa Kit Digital

## Contenido de este repositorio

- Estructura HTML de las páginas principales del sitio (inicio, contacto y páginas informativas)
- Hojas de estilo CSS originales del sitio
- Scripts JavaScript necesarios para la interactividad visual
- Recursos gráficos (imágenes, iconos, fuentes) utilizados en el diseño

No se incluyen las fichas de producto individuales ni las categorías de la tienda, al no ser relevantes para la muestra de portfolio.

## Propósito

Este repositorio se publica únicamente con fines de demostración profesional del trabajo de desarrollo y maquetación realizado sobre el sitio original. No tiene finalidad comercial ni sustituye al sitio web activo.
